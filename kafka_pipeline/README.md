Docker Compose
- The docker-compose configuration spins up a Kafka broker and a Kaftbat UI.
- Kafka broker external port: http://localhost:9034
- Kaftbat UI URL: http://localhost:8080
- Kafka Image: https://hub.docker.com/hardened-images/catalog/dhi/kafka/images
- Kafka UI Image: https://hub.docker.com/r/kafbat/kafka-ui
